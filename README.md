## Remote-Controlled Height-Adjustable Microphone Stand

### Project Overview
 
This project focuses on redesigning and improving an existing prototype of a microphone stand with remotely adjustable height. The stand allows users to change the microphone height to suit different speakers using a mobile application over Wi-Fi.

The existing design uses an electric motor and a lead-screw mechanism for controlled vertical positioning. The goal is to improve the mechanical design, electronics, software, and battery-powered operation.

### Project Goals

• Redesign selected mechanical parts and create 3D-printable components.

• Update the electrical schematic and design a printed circuit board (PCB).

• Improve motor position control and Wi-Fi communication.

• Optimize the battery power system.

• Assemble and test the improved prototype.

• Evaluate the product’s potential applications and market viability.
